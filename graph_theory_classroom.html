1. 什么是图？G = (V, E)

图论把现实问题抽象成点（Vertices/Nodes）和边（Edges）。点代表对象，边代表对象之间的关系。

  • V（顶点集）：图中所有节点的集合，例如建筑物、城市、课程、人群。
  • E（边集）：连接两个节点的边，可以是有向或无向，可以带权重。
  • 权重：边或点上的“代价/距离/时间/容量”。
基本定义

G = (V, E)

其中 V = {v₁, v₂, ..., vₙ}，E ⊆ V × V。

如果边带权重：G = (V, E, w)，w: E → ℝ。

takeaway：拿到题先问：谁是点？谁是边？边有没有方向？有没有权重？

1b. 常见图类型速查

无向图 Undirected

边没有方向，A–B 与 B–A 是同一条边。适合“连接关系”。

有向图 Directed

边有方向，A→B ≠ B→A。适合“单向流动/依赖”。

加权图 Weighted

每条边有权重（距离/时间/成本）。

完全图 Complete

任意两点之间都有边。n 个节点的完全图有 n(n−1)/2 条边。

树 Tree / 生成树 Spanning Tree

无环连通图。生成树包含原图所有顶点且边数 = n−1。

二分图 Bipartite

顶点可分为两组，边只跨组不连组内。适合“任务分配”。

1c. Königsberg 七桥问题：Eulerian 路径

问题：能否一次不重复地走过 Königsberg 的全部七座桥？欧拉把四块陆地抽象为点、七座桥抽象为边，证明：

  • 一个无向图存在 Eulerian 回路（起点=终点）当且仅当所有顶点的度数都是偶数。
  • 存在 Eulerian 路径（起点≠终点）当且仅当恰好有 0 或 2 个顶点的度数是奇数。
Königsberg 的度数

A: 5, B: 3, C: 3, D: 3 —— 四个奇度顶点。

因此：不存在 Eulerian 路径。

takeaway：判断能否“一笔画”不用试，只数每个点连了几条边（degree）。

2. 最短路径：Dijkstra

问题：给定加权图和起点 s，求 s 到所有其他顶点的最短距离。

数学表达

决策变量：设 d[v] 为从 s 到 v 的最短距离。

目标：最小化 d[t]（若只关心终点 t），或求出所有 d[v]。

递推关系（三角不等式）：

d[v] ≤ d[u] + w(u, v)   ∀(u, v) ∈ E

初始化：d[s] = 0，d[v] = +∞（v ≠ s）。

takeaway：Dijkstra 要求边权非负。时间复杂度 O((V+E) log V)。 
import networkx as nx
import matplotlib.pyplot as plt

G = nx.Graph()
G.add_weighted_edges_from([
    ('A', 'B', 4), ('A', 'C', 2), ('B', 'C', 1),
    ('B', 'D', 5), ('C', 'D', 8), ('C', 'E', 10),
    ('D', 'E', 2), ('D', 'F', 6), ('E', 'F', 3)
])

start, end = 'A', 'F'
length, path = nx.single_source_dijkstra(G, start, end)
print(f'Shortest path from {start} to {end}: {path}')
print(f'Total distance: {length}')

# Visualize the shortest path
pos = nx.spring_layout(G, seed=42)
plt.figure(figsize=(8, 5))
path_edges = list(zip(path, path[1:]))

# Draw all nodes and edges
nx.draw_networkx_nodes(G, pos, node_color='lightgray', node_size=1200)
nx.draw_networkx_nodes(G, pos, nodelist=path, node_color='lightgreen', node_size=1500)
nx.draw_networkx_labels(G, pos, font_size=12, font_weight='bold')
nx.draw_networkx_edges(G, pos, edge_color='lightgray', width=1.5)
# Highlight the shortest path
nx.draw_networkx_edges(G, pos, edgelist=path_edges, edge_color='green', width=3)
edge_labels = nx.get_edge_attributes(G, 'weight')
nx.draw_networkx_edge_labels(G, pos, edge_labels=edge_labels)
plt.title(f'Shortest Path {start}→{end}: {path} (distance={length})')
plt.axis('off')
plt.show()

3. 最小生成树：Minimum Spanning Tree

问题：选择一组边，连接图中所有顶点，且总权重最小。典型场景：布线、道路、管道。

数学表达

决策变量：xe ∈ {0, 1}，边 e 是否被选中。

目标函数：

min Σe∈E we · xe

约束：

  • 选中 n−1 条边：Σ xe = n − 1
  • 无环（对于任意非空子集 S ⊂ V，S 内部的边数 ≤ |S| − 1）
  • 连通性：选中边构成的子图连接所有顶点
takeaway：经典算法 Kruskal（按权重贪心加边）和 Prim（从一点逐步扩展）。 
import networkx as nx
import matplotlib.pyplot as plt

G = nx.Graph()
G.add_weighted_edges_from([
    ('A', 'B', 4), ('A', 'C', 2), ('B', 'C', 1),
    ('B', 'D', 5), ('C', 'D', 8), ('C', 'E', 10),
    ('D', 'E', 2), ('D', 'F', 6), ('E', 'F', 3)
])

mst = nx.minimum_spanning_tree(G, weight='weight')
print('MST edges:', list(mst.edges(data=True)))
print('Total MST weight:', mst.size(weight='weight'))

# Visualize
pos = nx.spring_layout(G, seed=42)
plt.figure(figsize=(8, 5))
nx.draw_networkx_nodes(G, pos, node_color='lightblue', node_size=1000)
nx.draw_networkx_labels(G, pos)
# Non-MST edges in gray
nx.draw_networkx_edges(G, pos, edge_color='lightgray', width=1)
# MST edges in red
nx.draw_networkx_edges(mst, pos, edge_color='red', width=2.5)
edge_labels = nx.get_edge_attributes(G, 'weight')
nx.draw_networkx_edge_labels(G, pos, edge_labels=edge_labels)
plt.title('Minimum Spanning Tree (red edges)')
plt.axis('off')
plt.show()

4. Hamiltonian 路径 / 圈 与 TSP

Hamiltonian 路径：经过图中每个顶点恰好一次的路径。Hamiltonian 圈：回到起点的闭合路径。TSP（旅行商问题）：在完全图中找最短的 Hamiltonian 圈。

TSP 数学表达

决策变量：xij ∈ {0, 1}，是否从 i 直接走到 j。

目标函数：

min Σi,j cij · xij

约束：

  • 每个点恰好进入一次：Σi xij = 1，∀j
  • 每个点恰好离开一次：Σj xij = 1，∀i
  • 消除子回路（subtour elimination）
takeaway：TSP 是 NP-hard。小规模可用整数规划精确求解；大规模用启发式。 
import pulp
import numpy as np
import networkx as nx
import matplotlib.pyplot as plt

# ===== 1. Data input =====
# nodes: list[str], city/node labels for printing and visualization
nodes = ['A', 'B', 'C', 'D']
# n: int, total number of nodes
n = len(nodes)
# dist: numpy.ndarray, shape (n, n), symmetric distance matrix; dist[i][j] is the travel distance from node i to j
dist = np.array([
    [0, 10, 15, 20],
    [10, 0, 35, 25],
    [15, 35, 0, 30],
    [20, 25, 30, 0]
])

# ===== 2. Create PuLP model =====
# prob: pulp.LpProblem instance, objective is to minimize total distance
prob = pulp.LpProblem('TSP_MILP', pulp.LpMinimize)

# ===== 3. Decision variables =====
# x: dict[str, dict[str, pulp.LpVariable]], binary variable x[i][j]
#    x[i][j] == 1 means the route contains a directed edge from node i to node j
#    Indices i, j are string labels from nodes
x = pulp.LpVariable.dicts('x', (nodes, nodes), cat='Binary')

# u: dict[str, pulp.LpVariable], MTZ subtour elimination auxiliary variables
#    Records the "visit order" of each node except the start, in range [2, n]
#    e.g. u['B'] = 2 means B is the 2nd visited node (start A is fixed at 1)
u = pulp.LpVariable.dicts('u', nodes, lowBound=2, upBound=n, cat='Continuous')

# ===== 4. Objective function =====
# Minimize the total travel distance of the TSP tour:
# sum_{i,j} dist[i][j] * x[i][j]
prob += pulp.lpSum(dist[nodes.index(i)][nodes.index(j)] * x[i][j]
                   for i in nodes for j in nodes)

# ===== 5. Constraints =====
# Constraint 1: no self-loops
# Meaning: the route cannot contain an edge from node i directly back to i
for i in nodes:
    prob += x[i][i] == 0

# Constraint 2: each node leaves exactly once
# Meaning: for each node i, exactly one outgoing edge is selected
for i in nodes:
    prob += pulp.lpSum(x[i][j] for j in nodes) == 1

# Constraint 3: each node enters exactly once
# Meaning: for each node j, exactly one incoming edge is selected
for j in nodes:
    prob += pulp.lpSum(x[i][j] for i in nodes) == 1

# Constraint 4: MTZ subtour elimination (Miller-Tucker-Zemlin)
# Meaning: if edge (i, j) is selected (x[i][j] == 1), then j's visit order must be at least 1 greater than i's;
#          this ensures a clear ordering and prevents multiple disconnected small cycles.
# Math form: u_i - u_j + n * x_{ij} <= n - 1, for all i, j != start
start = nodes[0]  # Fix A as the start
for i in nodes:
    if i == start:
        continue
    for j in nodes:
        if j == start:
            continue
        prob += u[i] - u[j] + n * x[i][j] <= n - 1

# ===== 6. Solve =====
prob.solve(pulp.PULP_CBC_CMD(msg=False))
print('Status:', pulp.LpStatus[prob.status])
print('Minimum distance:', pulp.value(prob.objective))

# ===== 7. Extract the tour from the solution =====
# next_node: dict[str, str], records the next node of each node to reconstruct the full route
next_node = {}
for i in nodes:
    for j in nodes:
        if pulp.value(x[i][j]) > 0.5:  # binary variable, 1 means selected
            next_node[i] = j

# route: list[str], nodes in visiting order
route = [start]
current = start
while True:
    current = next_node[current]
    route.append(current)
    if current == start:
        break
print('Best TSP route:', ' -> '.join(route))

# ===== 8. Visualize =====
# G: networkx.Graph, only used for layout, node ids 0..n-1
G = nx.complete_graph(n)
# pos: dict[int, np.ndarray], 2D coordinates of each node
pos = nx.circular_layout(G)

plt.figure(figsize=(6, 6))
# Draw nodes
nx.draw_networkx_nodes(G, pos, node_color='lightyellow', node_size=1500)
# Draw node labels
nx.draw_networkx_labels(G, pos, labels={i: nodes[i] for i in range(n)}, font_size=14)
# Draw all possible edges (light gray background)
nx.draw_networkx_edges(G, pos, edge_color='lightgray', width=1)
# Draw selected TSP edges (red)
# tour_edges: list[tuple[int, int]], convert route node names to networkx node ids
tour_edges = [(nodes.index(route[i]), nodes.index(route[i+1])) for i in range(len(route)-1)]
nx.draw_networkx_edges(G, pos, edgelist=tour_edges, edge_color='red', width=3)
plt.title(f'TSP Optimal Tour: {" -> ".join(route)} = {pulp.value(prob.objective):.0f}')
plt.axis('off')
plt.show()

4a. Hamiltonian Path：指定起点与终点

Hamiltonian 路径是经过每个顶点恰好一次、但不需要回到起点的路径。如果额外指定起点 s 和终点 t，它就变成很多实际问题的原型：快递从仓库 s 出发、最后到达中转站 t；巡逻从东门出发、最后到达西门；测序从起始片段走到终止片段。

与 TSP 的核心区别
  • TSP：起点 = 终点，形成一个闭合回路（cycle）。
  • Hamiltonian Path：起点 ≠ 终点，路径不闭合（path）。
  • 起点只能出去一次、不能进入；终点只能进入一次、不能出去。
  • 目标函数仍为总路程最短，但不再包含“终点 → 起点”的闭合边。
MILP 形式

决策变量：xij ∈ {0, 1}，是否从 i 直接走到 j。

目标函数：

min Σi,j cij · xij

约束：

  • 起点 s：离开一次、进入零次
  • 终点 t：进入一次、离开零次
  • 其余节点：进入一次、离开一次
  • MTZ 消除子回路（u[s] 固定为 1）
takeaway：把 TSP 的“闭合”条件去掉，并把一个节点设为只能进、另一个节点设为只能出，就得到了指定起终点的 Hamiltonian Path。 
import pulp
import numpy as np
import networkx as nx
import matplotlib.pyplot as plt

# ===== 1. Data input =====
# nodes: list[str], node labels
nodes = ['A', 'B', 'C', 'D', 'E']
# n: int, total number of nodes
n = len(nodes)
# dist: numpy.ndarray, shape (n, n), symmetric distance matrix
dist = np.array([
    [0,  8, 12, 18,  7],
    [8,  0, 15, 10, 11],
    [12, 15, 0,  6, 13],
    [18, 10, 6,  0,  9],
    [7,  11, 13, 9,  0]
])

# Specify start and end nodes
start = 'A'
end = 'E'

# ===== 2. Create model =====
prob = pulp.LpProblem('Hamiltonian_Path', pulp.LpMinimize)

# ===== 3. Decision variables =====
# x: dict[str, dict[str, pulp.LpVariable]], binary variable x[i][j]
#    x[i][j] == 1 means the path contains an edge from node i to node j
x = pulp.LpVariable.dicts('x', (nodes, nodes), cat='Binary')

# u: dict[str, pulp.LpVariable], MTZ subtour elimination auxiliary variables
#    Records visit order; start fixed at 1, others in range [2, n]
#    Data type: dict of continuous PuLP variables
u = pulp.LpVariable.dicts('u', nodes, lowBound=1, upBound=n, cat='Continuous')

# ===== 4. Objective function =====
# Minimize the total travel distance of the Hamiltonian path
prob += pulp.lpSum(dist[nodes.index(i)][nodes.index(j)] * x[i][j]
                   for i in nodes for j in nodes)

# ===== 5. Constraints =====
# Constraint 1: no self-loops
for i in nodes:
    prob += x[i][i] == 0

# Constraint 2: start leaves exactly once and never enters
prob += pulp.lpSum(x[start][j] for j in nodes if j != start) == 1
prob += pulp.lpSum(x[i][start] for i in nodes if i != start) == 0

# Constraint 3: end enters exactly once and never leaves
prob += pulp.lpSum(x[i][end] for i in nodes if i != end) == 1
prob += pulp.lpSum(x[end][j] for j in nodes if j != end) == 0

# Constraint 4: intermediate nodes enter once and leave once
for v in nodes:
    if v == start or v == end:
        continue
    prob += pulp.lpSum(x[i][v] for i in nodes if i != v) == 1
    prob += pulp.lpSum(x[v][j] for j in nodes if j != v) == 1

# Constraint 5: fix start visit order to 1
prob += u[start] == 1

# Constraint 6: MTZ subtour elimination
# Meaning: if edge (i, j) is selected, j's visit order must be greater than i's;
#          note j cannot be the start (its order is fixed).
for i in nodes:
    for j in nodes:
        if i == j or j == start:
            continue
        prob += u[i] - u[j] + n * x[i][j] <= n - 1

# ===== 6. Solve =====
prob.solve(pulp.PULP_CBC_CMD(msg=False))
print('Status:', pulp.LpStatus[prob.status])
print('Minimum distance:', pulp.value(prob.objective))

# ===== 7. Extract the path from the solution =====
# next_node: dict[str, str], records the next node of each node
next_node = {}
for i in nodes:
    for j in nodes:
        if pulp.value(x[i][j]) > 0.5:
            next_node[i] = j

route = [start]
current = start
while current != end:
    current = next_node[current]
    route.append(current)
print('Best Hamiltonian path:', ' -> '.join(route))

# ===== 8. Visualize =====
G = nx.complete_graph(n)
pos = nx.circular_layout(G)

plt.figure(figsize=(6, 6))
nx.draw_networkx_nodes(G, pos, node_color='lightyellow', node_size=1500)
# Start green, end red, others default labels
labels = {i: nodes[i] for i in range(n)}
nx.draw_networkx_labels(G, pos, labels=labels, font_size=14)
# All possible edges as background
nx.draw_networkx_edges(G, pos, edge_color='lightgray', width=1)
# Draw Hamiltonian path edges (red)
path_edges = [(nodes.index(route[i]), nodes.index(route[i+1]))
              for i in range(len(route) - 1)]
nx.draw_networkx_edges(G, pos, edgelist=path_edges, edge_color='red', width=3,
                       arrows=True, arrowstyle='->', arrowsize=20)
# Highlight start and end
nx.draw_networkx_nodes(G, pos, nodelist=[nodes.index(start)],
                       node_color='lightgreen', node_size=1800)
nx.draw_networkx_nodes(G, pos, nodelist=[nodes.index(end)],
                       node_color='lightcoral', node_size=1800)
plt.title(f'Hamiltonian Path {start} → {end}: {" -> ".join(route)} = {pulp.value(prob.objective):.0f}')
plt.axis('off')
plt.show()

5. 图着色 Graph Coloring

问题：给每个顶点分配一种“颜色”，使得相邻顶点颜色不同，且使用的颜色总数最少。应用：考试排期、化学品隔离、频率分配。

数学表达

决策变量：

  • cv ∈ {1, 2, ..., K}：顶点 v 的颜色编号
  • yk ∈ {0, 1}：颜色 k 是否被使用

目标函数：

min Σk=1K yk

约束：

  • 相邻顶点颜色不同：cu ≠ cv，∀(u, v) ∈ E
takeaway：最小着色数是 NP-hard。常用贪心算法或整数规划；实际问题常转化为“最少需要几个时间段”。 
import networkx as nx
import matplotlib.pyplot as plt

# Exam scheduling: courses are nodes; edges connect courses with common students
G = nx.Graph()
G.add_nodes_from(['Math', 'Physics', 'CS', 'English', 'History'])
G.add_edges_from([
    ('Math', 'Physics'), ('Math', 'CS'),
    ('Physics', 'English'), ('CS', 'History'),
    ('English', 'History')
])

# Greedy coloring
coloring = nx.coloring.greedy_color(G, strategy='largest_first')
num_colors = max(coloring.values()) + 1
print('Color assignment:', coloring)
print('Minimum time slots needed (greedy):', num_colors)

# Visualize
colors = ['#fca5a5', '#93c5fd', '#86efac', '#fde047', '#d8b4fe']
node_colors = [colors[coloring[n] % len(colors)] for n in G.nodes]
pos = nx.spring_layout(G, seed=42)
plt.figure(figsize=(7, 5))
nx.draw(G, pos, with_labels=True, node_color=node_colors, node_size=1500, font_size=11,
        edge_color='gray', width=2)
plt.title(f'Exam Scheduling as Graph Coloring ({num_colors} time slots)')
plt.axis('off')
plt.show()

6. 指派问题：Assignment / Bipartite Matching

问题：n 个工人完成 n 项任务，每人一项，每项一人，最小化总成本。这是二分图上的最小权完美匹配。

数学表达

决策变量：xij ∈ {0, 1}，工人 i 是否做任务 j。

目标函数：

min Σi,j cij · xij

约束：

  • 每个工人一项任务：Σj xij = 1，∀i
  • 每项任务一个工人：Σi xij = 1，∀j
takeaway：指派问题是 LP 松弛后自动得到整数解的特殊情况，可用匈牙利算法或 scipy.optimize.linear_sum_assignment。 
import numpy as np
import matplotlib.pyplot as plt
import networkx as nx
from scipy.optimize import linear_sum_assignment

# Cost matrix: rows = volunteer teams, columns = polluted river sections
teams = ['T1', 'T2', 'T3', 'T4']
sections = ['S1', 'S2', 'S3', 'S4']
cost = np.array([
    [9, 2, 7, 8],
    [6, 4, 3, 7],
    [5, 8, 1, 4],
    [7, 6, 9, 5]
])

row_ind, col_ind = linear_sum_assignment(cost)
print('Optimal assignment:')
for r, c in zip(row_ind, col_ind):
    print(f'  {teams[r]} → {sections[c]}, cost = {cost[r, c]}')

for r, c in zip(row_ind, col_ind):
    B.add_edge(f't_{teams[r]}', f's_{sections[c]}', weight=cost[r, c])

pos = {}
pos.update({f't_{t}': (0, i) for i, t in enumerate(teams)})
pos.update({f's_{s}': (1, i) for i, s in enumerate(sections)})

plt.figure(figsize=(6, 5))
left = [n for n in B.nodes if n.startswith('t_')]

7. 课程注册优化：Course Registration

问题（来自 PDF）：N 名学生、M 门课，每名学生最多选 2 门课，每门课有最大容量。如何最大化总体满意度？或如何最小化总运营成本？

数学表达

决策变量：xij ∈ {0, 1}，学生 i 是否选课程 j。

参数：

  • sij：学生 i 对课程 j 的满意度（或运营成本）
  • cj：课程 j 的容量
  • k = 2：每名学生最多选的课程数

目标函数（最大化满意度）：

max Σi,j sij · xij

约束：

  • 每名学生最多选 k 门：Σj xij ≤ k，∀i
  • 每门课不超过容量：Σi xij ≤ cj，∀j
takeaway：这是二分图上的整数规划，可用 PuLP / scipy / networkx 最大流求解。 
import numpy as np
import matplotlib.pyplot as plt
import networkx as nx
from scipy.optimize import linprog

# Data
students = ['S1', 'S2', 'S3', 'S4', 'S5']
courses = ['C1', 'C2', 'C3']
capacity = {'C1': 3, 'C2': 3, 'C3': 2}
max_courses_per_student = 2

# Random satisfaction matrix
np.random.seed(42)
satisfaction = np.random.randint(1, 10, size=(len(students), len(courses)))
print('Satisfaction matrix:')
print(satisfaction)

# Solve maximum satisfaction with PuLP
import pulp
prob = pulp.LpProblem('Course_Registration', pulp.LpMaximize)
x = pulp.LpVariable.dicts('x', ((i, j) for i in range(len(students)) for j in range(len(courses))), cat='Binary')
# Objective
prob += pulp.lpSum(satisfaction[i][j] * x[i, j] for i in range(len(students)) for j in range(len(courses)))
# Each student selects at most 2 courses
for i in range(len(students)):
    prob += pulp.lpSum(x[i, j] for j in range(len(courses))) <= max_courses_per_student
# Each course does not exceed capacity
for j, c in enumerate(courses):
    prob += pulp.lpSum(x[i, j] for i in range(len(students))) <= capacity[c]

prob.solve(pulp.PULP_CBC_CMD(msg=False))
print('\nOptimal assignments:')
assignments = []
for i, s in enumerate(students):
    for j, c in enumerate(courses):
        if pulp.value(x[i, j]) > 0.5:
            print(f'  {s} → {c} (satisfaction={satisfaction[i][j]})')
            assignments.append((s, c))
print('Total satisfaction:', pulp.value(prob.objective))

# Visualize
B = nx.DiGraph()
B.add_nodes_from([f's_{s}' for s in students], bipartite=0)
B.add_nodes_from([f'c_{c}' for c in courses], bipartite=1)
for s, c in assignments:
    B.add_edge(f's_{s}', f'c_{c}')

pos = {}
pos.update({f's_{s}': (0, i) for i, s in enumerate(students)})
pos.update({f'c_{c}': (1, i) for i, c in enumerate(courses)})

plt.figure(figsize=(7, 5))
left = [n for n in B.nodes if n.startswith('s_')]
right = [n for n in B.nodes if n.startswith('c_')]
nx.draw_networkx_nodes(B, pos, nodelist=left, node_color='lightblue', node_size=1200)
nx.draw_networkx_nodes(B, pos, nodelist=right, node_color='lightcoral', node_size=1200)
nx.draw_networkx_labels(B, pos, labels={n: n.split('_')[1] for n in B.nodes}, font_size=12)
nx.draw_networkx_edges(B, pos, edge_color='green', width=2, arrows=True,
                       connectionstyle='arc3,rad=0.05')
plt.title('Course Registration: Maximum Satisfaction Assignment')
plt.axis('off')
plt.show()

8. 工厂运输成本最小化：Factory → Supplier

问题（来自 PDF）：N 个工厂、M 个供应商，每条边代表运输成本。如何最小化总成本？如果每个供应商只服务一个工厂，就是运输问题 / 指派问题的扩展。

数学表达（运输问题）

决策变量：xij ≥ 0，从工厂 i 运往供应商 j 的货物量（或 0/1 是否连接）。

参数：

  • cij：工厂 i 到供应商 j 的单位运输成本
  • si：工厂 i 的供应量
  • dj：供应商 j 的需求量

目标函数：

min Σi,j cij · xij

约束：

  • 工厂出货量不超过供应：Σj xij ≤ si，∀i
  • 满足供应商需求：Σi xij = dj，∀j
takeaway：这是经典 Transportation Problem，可用线性规划（LP）求解；若 xij ∈ {0, 1} 且一一对应，则退化为指派问题。 
import numpy as np
import matplotlib.pyplot as plt
import networkx as nx
from scipy.optimize import linprog

factories = ['F1', 'F2', 'F3']
suppliers = ['S1', 'S2', 'S3', 'S4']

# Unit transportation cost matrix
cost = np.array([
    [4, 6, 9, 5],
    [7, 3, 5, 8],
    [5, 8, 4, 6]
], dtype=float)

supply = np.array([40, 50, 60], dtype=float)    # Factory capacity
demand = np.array([30, 40, 35, 45], dtype=float) # Supplier demand

# Balance check
print('Total supply:', supply.sum(), 'Total demand:', demand.sum())

# Solve with scipy.optimize.linprog (variables flattened as x_ij)
n_f, n_s = cost.shape
c = cost.flatten()
# Factory supply constraints: A_eq @ x = supply
A_eq = np.zeros((n_f + n_s, n_f * n_s))
b_eq = np.concatenate([supply, demand])
for i in range(n_f):
    A_eq[i, i*n_s:(i+1)*n_s] = 1
for j in range(n_s):
    for i in range(n_f):
        A_eq[n_f + j, i*n_s + j] = 1

res = linprog(c, A_eq=A_eq, b_eq=b_eq, bounds=(0, None), method='highs')
x_opt = res.x.reshape(n_f, n_s)
print('\nOptimal shipment plan:')
print(np.round(x_opt, 2))
print('Minimum total cost:', res.fun)

# Visualize transportation network
G = nx.DiGraph()
for f in factories:
    G.add_node(f, bipartite=0)
for s in suppliers:
    G.add_node(s, bipartite=1)

for i, f in enumerate(factories):
    for j, s in enumerate(suppliers):
        if x_opt[i, j] > 0.01:
            G.add_edge(f, s, weight=cost[i, j], amount=x_opt[i, j])

pos = {}
pos.update({f: (0, i) for i, f in enumerate(factories)})
pos.update({s: (1, i) for i, s in enumerate(suppliers)})

plt.figure(figsize=(8, 5))
left = [n for n in G.nodes if n in factories]
right = [n for n in G.nodes if n in suppliers]
nx.draw_networkx_nodes(G, pos, nodelist=left, node_color='lightblue', node_size=1500)
nx.draw_networkx_nodes(G, pos, nodelist=right, node_color='lightgreen', node_size=1500)
nx.draw_networkx_labels(G, pos, font_size=12)

# Edge width proportional to shipment amount
amounts = [G[u][v]['amount'] for u, v in G.edges]
max_amt = max(amounts) if amounts else 1
widths = [1 + 4 * amt / max_amt for amt in amounts]
nx.draw_networkx_edges(G, pos, edge_color='teal', width=widths, arrows=True,
                       connectionstyle='arc3,rad=0.05')
edge_labels = {(u, v): f"{d['amount']:.1f}\n({d['weight']:.0f})" for u, v, d in G.edges(data=True)}
nx.draw_networkx_edge_labels(G, pos, edge_labels=edge_labels, font_size=9)
plt.title('Factory → Supplier Transportation Plan (amount, cost)')
plt.axis('off')
plt.show()

10. 建模起手式：拿到题先填这 6 项

问题 示例
1. 节点 V 是什么？城市、建筑物、课程、人群、化学品
2. 边 E 是什么？道路、连接、冲突关系、依赖关系
3. 有向还是无向？道路双向用无向；物流/依赖用有向
4. 权重是什么？距离、时间、成本、交互次数
5. 约束是什么？必须经过某点、容量限制、不能同色
6. 优化目标是什么？最短、最小成本、最少颜色、最大覆盖
推荐库： networkx（图构建与经典算法）、 scipy.optimize（线性规划 / 指派问题）、 pulp（整数规划，适合选课、运输、TSP、着色）。

附录：节点位置与坐标系

图论只关心“谁和谁相连”，但节点在现实中的位置可以用任何坐标系描述。 位置信息通常作为节点属性存储，不参与图的连通性，却决定边权、距离和可视化方式。 下面介绍四种最常用的位置表示方法：二维直角坐标、地理坐标投影、三维空间坐标，以及从 OpenStreetMap 获取的真实街道网络坐标。

1. 二维直角坐标：最直接的位置定义

在 networkx 中，节点位置通常用一个字典 pos = {node: (x, y)} 表示。 这里的 x、y 可以是教室座位坐标、像素坐标、地图投影坐标，甚至是任意自定义的“特征空间”坐标。

关键概念
边权可以从坐标计算出来。例如两点之间的欧氏距离：

d = √((x₂−x₁)² + (y₂−y₁)²)

这样“位置”和“权重”就有了明确的数学关系。 
import networkx as nx
import matplotlib.pyplot as plt
import math

# Define 2D Cartesian coordinates (x, y) for each node directly
pos = {
    'A': (0, 0),
    'B': (3, 0),
    'C': (3, 4),
    'D': (6, 4),
    'E': (6, 0)
}

G = nx.Graph()
G.add_nodes_from(pos.keys())

# Compute Euclidean distance between every pair and use it as edge weight
for u in pos:
    for v in pos:
        if u < v:
            x1, y1 = pos[u]
            x2, y2 = pos[v]
            d = math.hypot(x2 - x1, y2 - y1)
            G.add_edge(u, v, weight=round(d, 2))

# Store coordinates as node attributes for later use
nx.set_node_attributes(G, pos, 'pos')

print('Node position attributes:', dict(G.nodes(data='pos')))
print('Edge weights:', dict(nx.get_edge_attributes(G, 'weight')))

nx.draw(G, pos, with_labels=True, node_color='lightblue',
        node_size=1200, font_size=11, font_weight='bold')
nx.draw_networkx_edge_labels(G, pos, edge_labels=nx.get_edge_attributes(G, 'weight'))
plt.title('2D Cartesian Node Positions')
plt.axis('off')
plt.show()

1.5 三维直角坐标：直接定义 (x, y, z) 与可旋转交互图

二维坐标不够用时，可以直接给每个节点赋予 (x, y, z) 三维直角坐标。 这在多层建筑、立体仓库、无人机路径、分子结构等场景中很常见。

关键概念
三维欧氏距离：

d = √((x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²)

用 Plotly 画出的 3D 图可以用鼠标旋转、缩放，适合向学生展示空间关系。 
import math
import plotly.graph_objects as go

# Define 3D Cartesian coordinates (x, y, z) for each node directly
pos3d = {
    'A': (0, 0, 0),
    'B': (3, 0, 0),
    'C': (3, 4, 0),
    'D': (3, 4, 2),
    'E': (0, 0, 2)
}

# Compute 3D Euclidean distance between every pair as edge weight
edges = []
weights = {}
for u in pos3d:
    for v in pos3d:
        if u < v:
            x1, y1, z1 = pos3d[u]

2. 地理坐标 → 平面直角坐标：投影

真实地球上的点用 纬度 φ、经度 λ 表示。若要在二维平面上计算距离，需要先做一次投影。 最简单的近似是 equirectangular 投影：

公式

x = R · λ · cos φ₀

y = R · φ

其中 R ≈ 6371 km，φ₀ 取所有点的平均纬度。适合小范围（如一个城市），大范围建议用 pyproj。

import math
import networkx as nx
import matplotlib.pyplot as plt

def to_rad(deg):
    return deg * math.pi / 180

def equirectangular(lat, lon, ref_lat):
    """Convert lat/lon (degrees) to local planar coordinates in km."""
    R = 6371.0
    x = R * to_rad(lon) * math.cos(to_rad(ref_lat))
    y = R * to_rad(lat)
    return x, y

cities = {
    'Beijing': (39.9042, 116.4074),
    'Shanghai': (31.2304, 121.4737),
    'Tokyo': (35.6762, 139.6503)
}

ref_lat = sum(c[0] for c in cities.values()) / len(cities)

G = nx.Graph()
for name, (lat, lon) in cities.items():
    x, y = equirectangular(lat, lon, ref_lat)
    G.add_node(name, lat=lat, lon=lon, x=x, y=y)

pos = {n: (G.nodes[n]['x'], G.nodes[n]['y']) for n in G.nodes}

# Add edges and compute planar distances after projection
for u in G.nodes:
    for v in G.nodes:
        if u < v:
            xu, yu = pos[u]
            xv, yv = pos[v]
            G.add_edge(u, v, planar=math.hypot(xv - xu, yv - yu))

nx.draw(G, pos, with_labels=True, node_color='lightgreen', node_size=1500,
        font_size=10, font_weight='bold')
edge_labels = nx.get_edge_attributes(G, 'planar')
nx.draw_networkx_edge_labels(G, pos, edge_labels={e: f'{v:.0f} km' for e, v in edge_labels.items()})
plt.title('Lat/Lon → Local Cartesian Projection')
plt.axis('off')
plt.show()

3. 三维直角坐标：ECEF 与空间直线距离

如果需要考虑海拔，或者想计算“穿过地球”的直线距离，可以把 lat/lon/alt 转成 地心地固坐标 ECEF (Earth-Centered Earth-Fixed)：

公式

x = (R + h) cos φ cos λ

y = (R + h) cos φ sin λ

z = (R + h) sin φ

这里的 R 是地球半径，h 是海拔。三维坐标下两点距离就是普通欧氏距离。

import math
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

def to_ecef(lat, lon, alt=0):
    """Simplified spherical ECEF conversion (lat/lon in degrees, alt in km)."""
    R = 6371.0
    lat_r = math.radians(lat)
    lon_r = math.radians(lon)
    r = R + alt
    x = r * math.cos(lat_r) * math.cos(lon_r)
    y = r * math.cos(lat_r) * math.sin(lon_r)
    z = r * math.sin(lat_r)
    return np.array([x, y, z])

cities = {
    'Beijing': (39.9042, 116.4074, 0),
    'London': (51.5074, -0.1278, 0),
    'New York': (40.7128, -74.0060, 0)
}

coords = {name: to_ecef(lat, lon, alt) for name, (lat, lon, alt) in cities.items()}

print('ECEF coordinates (km):')
for name, c in coords.items():
    print(f'{name}: ({c[0]:.1f}, {c[1]:.1f}, {c[2]:.1f})')

# 3D straight-line distance (chord length)
def chord_distance(c1, c2):
    return np.linalg.norm(c1 - c2)

names = list(coords.keys())
for i in range(len(names)):
    for j in range(i + 1, len(names)):
        d = chord_distance(coords[names[i]], coords[names[j]])
        print(f'{names[i]} — {names[j]} 3D chord distance: {d:.1f} km')

# Simple 3D visualization
fig = plt.figure(figsize=(8, 6))
ax = fig.add_subplot(111, projection='3d')
for name, c in coords.items():
    ax.scatter(*c, s=100, label=name)
    ax.text(c[0], c[1], c[2], name)
ax.set_xlabel('X (km)'); ax.set_ylabel('Y (km)'); ax.set_zlabel('Z (km)')
ax.set_title('ECEF 3D Coordinates')
ax.legend()
plt.show()

4. 真实街道网络：用 osmnx 获取节点坐标

在真实 GIS 数据中，节点就是街道交叉口，边就是路段。 osmnx 可以直接从 OpenStreetMap 下载某个城市的街道网络， 每个节点自带 y（纬度）和 x（经度）属性。

注意
运行本段需要安装 osmnx 并保持网络连接。它示范了如何把“真实地图”转化为可计算的图： 给定两个经纬度点，找到最近的网络节点，再用 Dijkstra 求最短路径。 
# @skip-test Requires osmnx and internet connection
import osmnx as ox
import networkx as nx
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
plt.show = lambda: None

# 1. Download city street network (drive = drivable roads)
place_name = "Cambridge, UK"
G = ox.graph_from_place(place_name, network_type="drive")

# 2. Given origin and destination lat/lon
origin_point = (52.2053, 0.1192)        # near King's College
destination_point = (52.2150, 0.1380)   # near Cambridge North Station

# 3. Find nearest road network nodes
orig_node = ox.distance.nearest_nodes(G, origin_point[1], origin_point[0])
dest_node = ox.distance.nearest_nodes(G, destination_point[1], destination_point[0])
print(f"Origin node: {orig_node}")
print(f"Destination node: {dest_node}")

# 4. Use Dijkstra to find shortest path (by road length weight='length')
shortest_path = nx.shortest_path(G, orig_node, dest_node, weight='length')
print(f"Shortest path has {len(shortest_path)} nodes.")

# 5. Plot the route on the map
fig, ax = ox.plot_graph(G, show=False, close=False, bgcolor='k',
                        node_size=10, edge_color='w', edge_linewidth=0.5,
                        figsize=(10, 10))
ox.plot_graph_route(G, shortest_path, node_size=0, route_color='r',
                    route_linewidth=4, ax=ax, show=True, close=True)

Haversine 公式

d = 2R · arcsin(√(sin²(Δφ/2) + cos φ₁ cos φ₂ sin²(Δλ/2)))

R ≈ 6371 km。该距离是地球表面的最短大圆距离，适合作为跨区域物流、航线等问题的边权。

教师参考
坐标系的选择取决于问题尺度： 教室内座位、机器人网格用二维直角坐标； 城市内道路用投影后的平面坐标； 洲际航线用经纬度 + Haversine； 需要考虑海拔或卫星轨道时用三维 ECEF。 关键是让学生理解：节点的“位置”只是一种属性，图的拓扑结构才是另一回事。
