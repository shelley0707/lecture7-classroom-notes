1. 什么是图？G = (V, E)

图论把现实问题抽象成点（Vertices/Nodes）和边（Edges）。点代表对象，边代表对象之间的关系。

  • V（顶点集）：图中所有节点的集合，例如建筑物、城市、课程、人群。
  • E（边集）：连接两个节点的边，可以是有向或无向，可以带权重。
  • 权重：边或点上的“代价/距离/时间/容量”。
基本定义

G = (V, E)

其中 V = {v₁, v₂, ..., vₙ}，E ⊆ V × V。

如果边带权重：G = (V, E, w)，w: E → ℝ。

takeaway：拿到题先问：谁是点？谁是边？边有没有方向？有没有权重？

1b. 常见图类型速查

无向图 Undirected

边没有方向，A–B 与 B–A 是同一条边。适合“连接关系”。

有向图 Directed

边有方向，A→B ≠ B→A。适合“单向流动/依赖”。

加权图 Weighted

每条边有权重（距离/时间/成本）。

完全图 Complete

任意两点之间都有边。n 个节点的完全图有 n(n−1)/2 条边。

树 Tree / 生成树 Spanning Tree

无环连通图。生成树包含原图所有顶点且边数 = n−1。

二分图 Bipartite

顶点可分为两组，边只跨组不连组内。适合“任务分配”。

1c. Königsberg 七桥问题：Eulerian 路径

问题：能否一次不重复地走过 Königsberg 的全部七座桥？欧拉把四块陆地抽象为点、七座桥抽象为边，证明：

  • 一个无向图存在 Eulerian 回路（起点=终点）当且仅当所有顶点的度数都是偶数。
  • 存在 Eulerian 路径（起点≠终点）当且仅当恰好有 0 或 2 个顶点的度数是奇数。
Königsberg 的度数

A: 5, B: 3, C: 3, D: 3 —— 四个奇度顶点。

因此：不存在 Eulerian 路径。

takeaway：判断能否“一笔画”不用试，只数每个点连了几条边（degree）。 
import networkx as nx
import matplotlib.pyplot as plt

# 四块陆地 A/B/C/D，七座桥
G = nx.MultiGraph()
G.add_nodes_from(['A', 'B', 'C', 'D'])
# 历史上的 Königsberg 桥连接关系
bridges = [
    ('A', 'B'), ('A', 'B'),  # A-B 两座桥
    ('A', 'C'), ('A', 'C'),  # A-C 两座桥
    ('A', 'D'),              # A-D 一座桥
    ('B', 'D'),              # B-D 一座桥
    ('C', 'D')               # C-D 一座桥
]
G.add_edges_from(bridges)

# 检查 Eulerian 路径
print('Degrees:', dict(G.degree()))
odd = [n for n, d in G.degree() if d % 2 == 1]
print(f'Odd-degree vertices: {odd} ({len(odd)} total)')
print('Has Eulerian path:', nx.has_eulerian_path(G))
print('Has Eulerian circuit:', nx.is_eulerian(G))

# 可视化：用弯曲的边表示 Multiple edges
pos = {
    'A': (0, 1),
    'B': (-1, 0),
    'C': (1, 0),
    'D': (0, -1)
}
plt.figure(figsize=(7, 6))
nx.draw_networkx_nodes(G, pos, node_color='lightcoral', node_size=2000, font_size=14)

plt.title('Königsberg Bridges: No Eulerian Path Exists')

2. 最短路径：Dijkstra

问题：给定加权图和起点 s，求 s 到所有其他顶点的最短距离。

数学表达

决策变量：设 d[v] 为从 s 到 v 的最短距离。

目标：最小化 d[t]（若只关心终点 t），或求出所有 d[v]。

递推关系（三角不等式）：

d[v] ≤ d[u] + w(u, v)   ∀(u, v) ∈ E

初始化：d[s] = 0，d[v] = +∞（v ≠ s）。

takeaway：Dijkstra 要求边权非负。时间复杂度 O((V+E) log V)。 
import networkx as nx
import matplotlib.pyplot as plt

G = nx.Graph()
G.add_weighted_edges_from([
    ('A', 'B', 4), ('A', 'C', 2), ('B', 'C', 1),
    ('B', 'D', 5), ('C', 'D', 8), ('C', 'E', 10),
    ('D', 'E', 2), ('D', 'F', 6), ('E', 'F', 3)
])

start, end = 'A', 'F'
length, path = nx.single_source_dijkstra(G, start, end)
print(f'Shortest path from {start} to {end}: {path}')
print(f'Total distance: {length}')

# 可视化最短路径
pos = nx.spring_layout(G, seed=42)
plt.figure(figsize=(8, 5))
path_edges = list(zip(path, path[1:]))

# 画所有节点和边
nx.draw_networkx_nodes(G, pos, node_color='lightgray', node_size=1200)
nx.draw_networkx_nodes(G, pos, nodelist=path, node_color='lightgreen', node_size=1500)
nx.draw_networkx_labels(G, pos, font_size=12, font_weight='bold')
nx.draw_networkx_edges(G, pos, edge_color='lightgray', width=1.5)
# 高亮最短路径
nx.draw_networkx_edges(G, pos, edgelist=path_edges, edge_color='green', width=3)
edge_labels = nx.get_edge_attributes(G, 'weight')
nx.draw_networkx_edge_labels(G, pos, edge_labels=edge_labels)
plt.title(f'Shortest Path {start}→{end}: {path} (distance={length})')
plt.axis('off')
plt.show()

3. 最小生成树：Minimum Spanning Tree

问题：选择一组边，连接图中所有顶点，且总权重最小。典型场景：布线、道路、管道。

数学表达

决策变量：xe ∈ {0, 1}，边 e 是否被选中。

目标函数：

min Σe∈E we · xe

约束：

  • 选中 n−1 条边：Σ xe = n − 1
  • 无环（对于任意非空子集 S ⊂ V，S 内部的边数 ≤ |S| − 1）
  • 连通性：选中边构成的子图连接所有顶点
takeaway：经典算法 Kruskal（按权重贪心加边）和 Prim（从一点逐步扩展）。 
import networkx as nx
import matplotlib.pyplot as plt

G = nx.Graph()
G.add_weighted_edges_from([
    ('A', 'B', 4), ('A', 'C', 2), ('B', 'C', 1),
    ('B', 'D', 5), ('C', 'D', 8), ('C', 'E', 10),
    ('D', 'E', 2), ('D', 'F', 6), ('E', 'F', 3)
])

mst = nx.minimum_spanning_tree(G, weight='weight')
print('MST edges:', list(mst.edges(data=True)))
print('Total MST weight:', mst.size(weight='weight'))

# 可视化
pos = nx.spring_layout(G, seed=42)
plt.figure(figsize=(8, 5))
nx.draw_networkx_nodes(G, pos, node_color='lightblue', node_size=1000)
nx.draw_networkx_labels(G, pos)
# 非 MST 边灰色
nx.draw_networkx_edges(G, pos, edge_color='lightgray', width=1)
# MST 边红色

edge_labels = nx.get_edge_attributes(G, 'weight')
nx.draw_networkx_edge_labels(G, pos, edge_labels=edge_labels)
plt.title('Minimum Spanning Tree (red edges)')
plt.axis('off')
plt.show()

4. Hamiltonian 路径 / 圈 与 TSP

Hamiltonian 路径：经过图中每个顶点恰好一次的路径。Hamiltonian 圈：回到起点的闭合路径。TSP（旅行商问题）：在完全图中找最短的 Hamiltonian 圈。

TSP 数学表达

决策变量：xij ∈ {0, 1}，是否从 i 直接走到 j。

目标函数：

min Σi,j cij · xij

约束：

  • 每个点恰好进入一次：Σi xij = 1，∀j
  • 每个点恰好离开一次：Σj xij = 1，∀i
  • 消除子回路（subtour elimination）
takeaway：TSP 是 NP-hard。小规模可用整数规划精确求解；大规模用启发式。 
import itertools
import numpy as np
import networkx as nx
import matplotlib.pyplot as plt

nodes = ['A', 'B', 'C', 'D']
dist = np.array([
    [0, 10, 15, 20],
    [10, 0, 35, 25],
    [15, 35, 0, 30],
    [20, 25, 30, 0]
])

# 暴力枚举最优 TSP 回路
best = None
best_cost = float('inf')
for perm in itertools.permutations(range(1, len(nodes))):
    route = (0,) + perm + (0,)
    cost = sum(dist[route[i]][route[i+1]] for i in range(len(route)-1))
    if cost < best_cost:
        best_cost = cost
        best = route

best_route = [nodes[i] for i in best]
print('Best TSP route:', best_route)
print('Minimum distance:', best_cost)

# 可视化最优回路
G = nx.complete_graph(len(nodes))
pos = nx.circular_layout(G)
plt.figure(figsize=(6, 6))
nx.draw_networkx_nodes(G, pos, node_color='lightyellow', node_size=1500)
nx.draw_networkx_labels(G, pos, labels={i: nodes[i] for i in range(len(nodes))}, font_size=14)

# 画所有边（灰色）
nx.draw_networkx_edges(G, pos, edge_color='lightgray', width=1)
# 画 TSP 回路（红色）
tour_edges = list(zip(best, best[1:]))
nx.draw_networkx_edges(G, pos, edgelist=tour_edges, edge_color='red', width=3)
plt.title(f'TSP Optimal Tour: {" → ".join(best_route)} = {best_cost}')
plt.axis('off')
plt.show()

5. 图着色 Graph Coloring

问题：给每个顶点分配一种“颜色”，使得相邻顶点颜色不同，且使用的颜色总数最少。应用：考试排期、化学品隔离、频率分配。

数学表达

决策变量：

  • cv ∈ {1, 2, ..., K}：顶点 v 的颜色编号
  • yk ∈ {0, 1}：颜色 k 是否被使用

目标函数：

min Σk=1K yk

约束：

  • 相邻顶点颜色不同：cu ≠ cv，∀(u, v) ∈ E
takeaway：最小着色数是 NP-hard。常用贪心算法或整数规划；实际问题常转化为“最少需要几个时间段”。 
import networkx as nx
import matplotlib.pyplot as plt

# 考试排期：课程为节点，有共同学生的课程连边
G = nx.Graph()
G.add_nodes_from(['Math', 'Physics', 'CS', 'English', 'History'])
G.add_edges_from([
    ('Math', 'Physics'), ('Math', 'CS'),
    ('Physics', 'English'), ('CS', 'History'),
    ('English', 'History')
])

# 贪心着色

num_colors = max(coloring.values()) + 1
print('Color assignment:', coloring)
print('Minimum time slots needed (greedy):', num_colors)

# 可视化

6. 指派问题：Assignment / Bipartite Matching

问题：n 个工人完成 n 项任务，每人一项，每项一人，最小化总成本。这是二分图上的最小权完美匹配。

数学表达

决策变量：xij ∈ {0, 1}，工人 i 是否做任务 j。

目标函数：

min Σi,j cij · xij

约束：

  • 每个工人一项任务：Σj xij = 1，∀i
  • 每项任务一个工人：Σi xij = 1，∀j
takeaway：指派问题是 LP 松弛后自动得到整数解的特殊情况，可用匈牙利算法或 scipy.optimize.linear_sum_assignment。 
import numpy as np
import matplotlib.pyplot as plt
import networkx as nx
from scipy.optimize import linear_sum_assignment

# 成本矩阵：行 = 志愿者队伍，列 = 污染河段
teams = ['T1', 'T2', 'T3', 'T4']
sections = ['S1', 'S2', 'S3', 'S4']
cost = np.array([
    [9, 2, 7, 8],
    [6, 4, 3, 7],
    [5, 8, 1, 4],
    [7, 6, 9, 5]
])

row_ind, col_ind = linear_sum_assignment(cost)
print('Optimal assignment:')
for r, c in zip(row_ind, col_ind):
    print(f'  {teams[r]} → {sections[c]}, cost = {cost[r, c]}')
print('Total minimum cost:', cost[row_ind, col_ind].sum())

# 可视化二分图匹配
B = nx.DiGraph()
B.add_nodes_from([f't_{t}' for t in teams], bipartite=0)
B.add_nodes_from([f's_{s}' for s in sections], bipartite=1)
for r, c in zip(row_ind, col_ind):
    B.add_edge(f't_{teams[r]}', f's_{sections[c]}', weight=cost[r, c])

pos = {}
pos.update({f't_{t}': (0, i) for i, t in enumerate(teams)})
pos.update({f's_{s}': (1, i) for i, s in enumerate(sections)})

plt.figure(figsize=(6, 5))
left = [n for n in B.nodes if n.startswith('t_')]
right = [n for n in B.nodes if n.startswith('s_')]
nx.draw_networkx_nodes(B, pos, nodelist=left, node_color='lightblue', node_size=1200)
nx.draw_networkx_nodes(B, pos, nodelist=right, node_color='lightgreen', node_size=1200)
nx.draw_networkx_labels(B, pos, labels={n: n.split('_')[1] for n in B.nodes}, font_size=12)
nx.draw_networkx_edges(B, pos, edge_color='red', width=2, arrows=True,
                       connectionstyle='arc3,rad=0.1')
edge_labels = nx.get_edge_attributes(B, 'weight')
nx.draw_networkx_edge_labels(B, pos, edge_labels=edge_labels)
plt.title('Optimal Assignment (Minimum Cost Bipartite Matching)')
plt.axis('off')
plt.show()

7. 课程注册优化：Course Registration

问题（来自 PDF）：N 名学生、M 门课，每名学生最多选 2 门课，每门课有最大容量。如何最大化总体满意度？或如何最小化总运营成本？

数学表达

决策变量：xij ∈ {0, 1}，学生 i 是否选课程 j。

参数：

  • sij：学生 i 对课程 j 的满意度（或运营成本）
  • cj：课程 j 的容量
  • k = 2：每名学生最多选的课程数

目标函数（最大化满意度）：

max Σi,j sij · xij

约束：

  • 每名学生最多选 k 门：Σj xij ≤ k，∀i
  • 每门课不超过容量：Σi xij ≤ cj，∀j
takeaway：这是二分图上的整数规划，可用 PuLP / scipy / networkx 最大流求解。 
import numpy as np
import matplotlib.pyplot as plt
import networkx as nx
from scipy.optimize import linprog

# 数据
students = ['S1', 'S2', 'S3', 'S4', 'S5']
courses = ['C1', 'C2', 'C3']
capacity = {'C1': 3, 'C2': 3, 'C3': 2}
max_courses_per_student = 2

# 随机满意度矩阵
np.random.seed(42)
satisfaction = np.random.randint(1, 10, size=(len(students), len(courses)))
print('Satisfaction matrix:')
print(satisfaction)

# 用 PuLP 求解最大化满意度
# pip install pulp
import pulp
prob = pulp.LpProblem('Course_Registration', pulp.LpMaximize)
x = pulp.LpVariable.dicts('x', ((i, j) for i in range(len(students)) for j in range(len(courses))), cat='Binary')
# 目标
prob += pulp.lpSum(satisfaction[i][j] * x[i, j] for i in range(len(students)) for j in range(len(courses)))
# 每名学生最多选 2 门
for i in range(len(students)):
    prob += pulp.lpSum(x[i, j] for j in range(len(courses))) <= max_courses_per_student
# 每门课不超过容量
for j, c in enumerate(courses):
    prob += pulp.lpSum(x[i, j] for i in range(len(students))) <= capacity[c]

prob.solve(pulp.PULP_CBC_CMD(msg=False))
print('\nOptimal assignments:')
assignments = []
for i, s in enumerate(students):
    for j, c in enumerate(courses):
        if pulp.value(x[i, j]) > 0.5:
            print(f'  {s} → {c} (satisfaction={satisfaction[i][j]})')
            assignments.append((s, c))
print('Total satisfaction:', pulp.value(prob.objective))

# 可视化
B = nx.DiGraph()
B.add_nodes_from([f's_{s}' for s in students], bipartite=0)
B.add_nodes_from([f'c_{c}' for c in courses], bipartite=1)
for s, c in assignments:
    B.add_edge(f's_{s}', f'c_{c}')

pos = {}
pos.update({f's_{s}': (0, i) for i, s in enumerate(students)})
pos.update({f'c_{c}': (1, i) for i, c in enumerate(courses)})

plt.figure(figsize=(7, 5))
left = [n for n in B.nodes if n.startswith('s_')]
right = [n for n in B.nodes if n.startswith('c_')]
nx.draw_networkx_nodes(B, pos, nodelist=left, node_color='lightblue', node_size=1200)
nx.draw_networkx_nodes(B, pos, nodelist=right, node_color='lightcoral', node_size=1200)
nx.draw_networkx_labels(B, pos, labels={n: n.split('_')[1] for n in B.nodes}, font_size=12)
nx.draw_networkx_edges(B, pos, edge_color='green', width=2, arrows=True,
                       connectionstyle='arc3,rad=0.05')
plt.title('Course Registration: Maximum Satisfaction Assignment')
plt.axis('off')
plt.show()

8. 工厂运输成本最小化：Factory → Supplier

问题（来自 PDF）：N 个工厂、M 个供应商，每条边代表运输成本。如何最小化总成本？如果每个供应商只服务一个工厂，就是运输问题 / 指派问题的扩展。

数学表达（运输问题）

决策变量：xij ≥ 0，从工厂 i 运往供应商 j 的货物量（或 0/1 是否连接）。

参数：

  • cij：工厂 i 到供应商 j 的单位运输成本
  • si：工厂 i 的供应量
  • dj：供应商 j 的需求量

目标函数：

min Σi,j cij · xij

约束：

  • 工厂出货量不超过供应：Σj xij ≤ si，∀i
  • 满足供应商需求：Σi xij = dj，∀j
takeaway：这是经典 Transportation Problem，可用线性规划（LP）求解；若 xij ∈ {0, 1} 且一一对应，则退化为指派问题。 
import numpy as np
import matplotlib.pyplot as plt
import networkx as nx
from scipy.optimize import linprog

factories = ['F1', 'F2', 'F3']
suppliers = ['S1', 'S2', 'S3', 'S4']

# 单位运输成本矩阵
cost = np.array([
    [4, 6, 9, 5],
    [7, 3, 5, 8],
    [5, 8, 4, 6]
], dtype=float)

supply = np.array([40, 50, 60], dtype=float)   # 工厂产能
demand = np.array([30, 40, 35, 45], dtype=float) # 供应商需求

# 平衡检查
print('Total supply:', supply.sum(), 'Total demand:', demand.sum())

# 用 scipy.optimize.linprog 求解（变量展平为 x_ij）
n_f, n_s = cost.shape
c = cost.flatten()
# 工厂供应约束：A_eq @ x = supply
A_eq = np.zeros((n_f + n_s, n_f * n_s))
b_eq = np.concatenate([supply, demand])
for i in range(n_f):
    A_eq[i, i*n_s:(i+1)*n_s] = 1
for j in range(n_s):
    for i in range(n_f):
        A_eq[n_f + j, i*n_s + j] = 1

2. SIR 烟扩散模型：状态、转移与参数

为什么用 SIR？传染病模型和烟雾扩散有一个共同结构：某种‘东西’通过接触/邻接关系从一个单元传到另一个单元。我们可以借用 SIR 的框架：

  • S（Safe）：尚未被烟波及的区域。
  • I（Infected）：烟雾浓度超过安全阈值，处于危险中。
  • R（Recovered）：烟雾被排出或中和，区域重新安全。

转移规则：每个时间步，S 节点如果与 I 节点相邻，就以一定概率变成 I；I 节点以恢复率 γ 变成 R。边越长，传播概率越低。

def run_smoke_simulation(graph, fire_origin,
                         base_propagation_rate,  # base probability that smoke spreads from I to S per step
                         decay_factor,           # how much edge length reduces propagation rate
                         recovery_rate,          # base probability that I becomes R per step
                         intervention_boost,     # extra recovery rate when intervention is active
                         intervention_start):    # earliest time step intervention may activate
    """Run one stochastic SIR-style smoke simulation on the mall graph."""
    G_sim = graph.copy()
    for node in G_sim.nodes():
        G_sim.nodes[node]['state'] = 'S'
        G_sim.nodes[node]['infected_time'] = -1

    G_sim.nodes[fire_origin]['state'] = 'I'
    G_sim.nodes[fire_origin]['infected_time'] = 0

    intervention_active = False
    num_time_steps = 100
    network_states_over_time = []

    def counts(g):
        s = sum(1 for n in g.nodes() if g.nodes[n]['state'] == 'S')
        i = sum(1 for n in g.nodes() if g.nodes[n]['state'] == 'I')
        r = sum(1 for n in g.nodes() if g.nodes[n]['state'] == 'R')
        return s, i, r

    for t in range(num_time_steps):
        if t >= intervention_start and not intervention_active:
            if random.random() < 0.8:
                intervention_active = True

        new_states = {}
        for node in G_sim.nodes():
            current_state = G_sim.nodes[node]['state']
            new_states[node] = current_state

            if current_state == 'S':
                for neighbor in G_sim.neighbors(node):
                    if G_sim.nodes[neighbor]['state'] == 'I':
                        length = G_sim.edges[neighbor, node]['length']
                        adjusted_rate = base_propagation_rate / (1 + decay_factor * length)
                        if random.random() < adjusted_rate:
                            new_states[node] = 'I'
                            G_sim.nodes[node]['infected_time'] = t
                            break
            elif current_state == 'I':
                gamma = recovery_rate
                if intervention_active:
                    gamma += intervention_boost
                if random.random() < gamma:
                    new_states[node] = 'R'

        for node, state in new_states.items():
            G_sim.nodes[node]['state'] = state

        network_states_over_time.append({n: G_sim.nodes[n]['state'] for n in G_sim.nodes()})

        s, i, r = counts(G_sim)
        if s == 0:
            return t, network_states_over_time

    return num_time_steps, network_states_over_time

回答 C：在快速疏散场景中，R 可能不太合理，因为火灾现场很少在几分钟内‘恢复’；可以把 recovery_rate 设为 0，只看 S→I。

                            new_states[node] = 'I'
                            break
            elif state == 'I':
                gamma = recovery_rate + (intervention_boost if intervention_active else 0)
                if random.random() < gamma:
                    new_states[node] = 'R'
        for node, state in new_states.items():
            G_sim.nodes[node]['state'] = state
        if sum(1 for n in G_sim.nodes() if G_sim.nodes[n]['state'] == 'S') == 0:
            return t
    return 100


def avg_time(prop_rate, rec_rate, num_sims=50):
    times = []
    for _ in range(num_sims):
        t = run_smoke_simulation(
            G_smoke, 'Retail_A', prop_rate, 0.2, rec_rate, 0.0, 5
        )
        times.append(t)
    return np.mean(times)


# Parameter grid.
prop_rates = np.linspace(0.05, 0.30, 6)
rec_rates = np.linspace(0.0, 0.30, 6)

results = np.zeros((len(rec_rates), len(prop_rates)))
for i, rec in enumerate(rec_rates):

下面以一个简化的“最优单扇门”问题为例：枚举删除每条边，分别运行多次模拟，看哪条边 removal 能最大程度保护店铺节点。

import random
import numpy as np
import matplotlib.pyplot as plt
import networkx as nx

# Setup graph.
G_smoke = nx.Graph()
nodes_data = {
    'Retail_A': {'type': 'store', 'pos': (0, 0)},
    'Retail_B': {'type': 'store', 'pos': (1, 0)},
    'Retail_C': {'type': 'store', 'pos': (0, -1)},
    'Corridor_1': {'type': 'corridor', 'pos': (0.5, 0.5)},
    'Corridor_2': {'type': 'corridor', 'pos': (0.5, -0.5)},
    'Escalator_Up': {'type': 'escalator', 'pos': (1.5, 0.5)},
    'Escalator_Down': {'type': 'escalator', 'pos': (1.5, -0.5)},
    'Stairwell_1': {'type': 'stairwell', 'pos': (2, 0)},
    'Equipment_Room': {'type': 'utility', 'pos': (-0.5, -0.5)}
}
for node_id, data in nodes_data.items():
    G_smoke.add_node(node_id, type=data['type'], pos=data['pos'])
G_smoke.add_edges_from([
    ('Retail_A', 'Corridor_1'), ('Corridor_1', 'Retail_B'),
    ('Retail_A', 'Corridor_2'), ('Corridor_2', 'Retail_C'),
    ('Retail_B', 'Escalator_Up'), ('Escalator_Up', 'Stairwell_1'),
    ('Retail_C', 'Escalator_Down'), ('Escalator_Down', 'Stairwell_1'),
    ('Corridor_2', 'Equipment_Room'), ('Stairwell_1', 'Retail_B'),
    ('Corridor_1', 'Stairwell_1')
])
pos = nx.get_node_attributes(G_smoke, 'pos')
for u, v in G_smoke.edges():
    G_smoke.edges[u, v]['length'] = np.linalg.norm(np.array(pos[u]) - np.array(pos[v]))


def run_smoke_simulation(graph, fire_origin, base_propagation_rate=0.1,
                         decay_factor=0.2, recovery_rate=0.0):
    G_sim = graph.copy()
    for node in G_sim.nodes():
        G_sim.nodes[node]['state'] = 'S'
    G_sim.nodes[fire_origin]['state'] = 'I'
    states_over_time = []
    for t in range(100):
        new_states = {}
        for node in G_sim.nodes():
            state = G_sim.nodes[node]['state']
            new_states[node] = state
            if state == 'S':
                for neighbor in G_sim.neighbors(node):
                    if G_sim.nodes[neighbor]['state'] == 'I':
                        length = G_sim.edges[neighbor, node]['length']
                        rate = base_propagation_rate / (1 + decay_factor * length)
                        if random.random() < rate:
                            new_states[node] = 'I'
                            break
        for node, state in new_states.items():
            G_sim.nodes[node]['state'] = state
        states_over_time.append({n: G_sim.nodes[n]['state'] for n in G_sim.nodes()})
        if sum(1 for n in G_sim.nodes() if G_sim.nodes[n]['state'] == 'S') == 0:
            return states_over_time
    return states_over_time


store_nodes = [n for n, d in G_smoke.nodes(data=True) if d['type'] == 'store']
num_sims = 50

# Baseline: average affected stores over time.
baseline_counts = []
for _ in range(num_sims):
    states = run_smoke_simulation(G_smoke, 'Retail_A')
    counts = [sum(1 for n, s in st.items() if n in store_nodes and s == 'I') for st in states]
    baseline_counts.append(counts)
max_len = max(len(c) for c in baseline_counts)
baseline_padded = [c + [c[-1]] * (max_len - len(c)) for c in baseline_counts]
baseline_avg = np.array(baseline_padded).mean(axis=0)

# Test removing each edge.
edge_results = []
for u, v in G_smoke.edges():
    G_test = G_smoke.copy()
    G_test.remove_edge(u, v)
    counts_runs = []
    for _ in range(num_sims):
        states = run_smoke_simulation(G_test, 'Retail_A')
        counts = [sum(1 for n, s in st.items() if n in store_nodes and s == 'I') for st in states]
        counts_runs.append(counts)
    max_len = max(len(c) for c in counts_runs)
    padded = [c + [c[-1]] * (max_len - len(c)) for c in counts_runs]
    avg = np.array(padded).mean(axis=0)
    # Score: area under infected-store curve (smaller = better)
    score = avg.sum()
    edge_results.append(((u, v), score, avg))

edge_results.sort(key=lambda x: x[1])

print("Top 3 most effective single edges to block:")
for (u, v), score, _ in edge_results[:3]:
    print(f"  {u} - {v}: infected-store-time score = {score:.2f}")

# Plot top 2 vs baseline.
plt.figure(figsize=(10, 5))
plt.plot(baseline_avg, label='Baseline', color='blue')
for (u, v), _, avg in edge_results[:2]:
    plt.plot(avg, label=f'Block {u}-{v}')
plt.xlabel('Time step')
plt.ylabel('Avg infected stores')
plt.title('Optimal Single Isolation Door Comparison')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

Q1：如果只允许关一扇门，应该关哪一扇？怎么判断？

参考方向：通过枚举每条边被删除后的模拟结果，比较‘感染店铺数-时间’曲线下面积。面积最小的边就是最该关闭的隔离门位置。这是一种图上的‘边删除优化’。

Q2（开放）：如何把人员疏散也加入这个模型？

回答 A：为每个人员设置一个‘智能体’，在每个时间步根据当前烟雾状态和最近出口决定移动方向。

回答 B：在边上加入容量限制：一条走廊同一时间只能通过有限人数，模拟拥堵。

回答 C：把疏散过程也看作网络上的流问题：最大化从危险节点到出口的安全流量。

回答 D：考虑人的行为不确定性：有人熟悉路线、有人逆行、有人停留，需要用随机性或规则系统建模。

Q3（开放）：这个烟雾扩散模型最大的局限是什么？

回答 A：没有温度、热辐射、烟气分层等物理量，只是接触传播。

回答 B：参数（传播率、恢复率）高度抽象，需要大量校准。

回答 C：没有考虑建筑的三维结构：楼梯井实际上会加速竖向蔓延。

回答 D：没有考虑人的行为与疏散决策，无法评估真实伤亡风险。
